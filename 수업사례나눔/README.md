# 용인대일초등학교 수업사례나눔

누구나 로그인 없이 수업사례와 자료를 게시하고, 오늘의 한 줄을 나눌 수 있는 웹앱입니다. 게시물과 자료는 인터넷에 공개되므로 학생 개인정보와 자료의 공유 권한을 반드시 확인해야 합니다.

## 실행

Node.js 24 이상이 필요합니다. PowerShell에서 이 폴더로 이동하여 다음을 실행합니다.

```powershell
npm.cmd install
npm.cmd run build
$env:ADMIN_PASSWORD = "충분히 길고 무작위인 관리자 비밀번호"
npm.cmd start
```

브라우저에서 `http://localhost:3000`을 엽니다. 관리자 비밀번호는 매 실행 환경에 안전하게 설정해야 하며, 설정하지 않으면 관리자 기능을 사용할 수 없습니다. 일반 이용자는 로그인 없이 게시할 수 있습니다. 게시물마다 설정한 비밀번호를 잊으면 운영자에게 삭제를 요청해야 합니다.

## 포함된 기능

- 1~6학년별 교과 선택, 사례 등록·조회·수정·삭제, 검색과 페이지 탐색.
- 안전한 HTML 서식·링크, YouTube 주소, 이미지 및 PPT/PPTX/HWP/HWPX/PDF 첨부.
- 전송 전에 파일 개인정보 확인, 게시·수정 전에 전체 내용 확인. 이는 작성자의 자가 점검이며 자동 탐지가 아닙니다.
- 한 줄, 브라우저별 공감과 댓글, 게시물 비밀번호, 신고 및 관리자 신고함.
- 데이터는 `data\community.sqlite`에 저장됩니다. 서버를 다시 시작해도 유지됩니다. 새 글은 목록을 다시 열거나 새로고침하면 보이며, 새로고침 없는 실시간 반영은 구현하지 않았습니다.

## 웹 배포 시 필수 사항

이 구현은 계획 문서의 PostgreSQL·객체 스토리지 대신 **Node.js 단일 서버와 SQLite**를 사용하는 간단한 시작 구성입니다. 테스트와 소규모 단일 인스턴스 운영에 적합하며, 여러 서버 인스턴스 사이에서 데이터를 공유하지 않습니다. 대규모 운영이나 자동 확장에는 공용 데이터베이스·객체 스토리지로 전환해야 합니다.

1. Node.js 24 이상을 지원하는 서버에 프로젝트를 배포하고 `npm ci`, `npm run build`, `npm start`를 실행합니다. `PORT`로 포트를, `DATA_DIR`로 데이터 디렉터리를 지정할 수 있습니다.
2. `DATA_DIR`을 재배포·재시작에도 유지되는 영구 볼륨으로 지정합니다. 임시 파일시스템이나 서버리스 환경에서는 게시물이 사라질 수 있습니다. 볼륨에는 SQLite DB와 WAL 파일이 함께 있어야 합니다.
3. HTTPS를 적용하고 `ADMIN_PASSWORD`를 호스팅 환경의 비밀 설정에 등록합니다. 다른 사람에게 비밀번호를 공유하지 않습니다. 서버를 직접 공개하기 전 학교 담당자와 공개 서비스 운영 및 개인정보·저작권 정책을 확인합니다.
4. SQLite를 일관된 상태로 백업하고 복원 시험을 정기적으로 수행합니다. 단순히 실행 중인 DB 파일 하나만 복사하면 WAL에 남은 데이터가 누락될 수 있습니다. 저장 공간·파일 크기·트래픽을 감시합니다.
5. 공개 업로드는 확장자와 파일 시그니처만 확인하며 **악성 파일 검사나 학생 얼굴·개인정보 자동 탐지 기능은 없습니다**. 공개 운영 전 바이러스 검사, 스팸 대응, 신고 검토 및 유해 자료 삭제 체계를 준비해야 합니다. 요청 제한은 단일 프로세스 메모리 기준이므로 프록시·분산 환경에서는 별도의 제한 설정이 필요합니다.
6. 게시물의 사진과 자료는 누구나 다운로드할 수 있으며, 삭제 전에 복사된 자료나 백업은 자동 회수되지 않습니다. 신고함은 최근 100건을 표시하므로 운영자가 주기적으로 처리해야 합니다.

자료 파일은 개당 50MB 이하 10개, 이미지는 개당 10MB 이하 20개까지이며, 한 번에 전송할 새 파일 합계는 60MB 이하입니다.
